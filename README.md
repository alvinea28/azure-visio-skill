# Azure Visio Skill

Turn requirements or sketches into **editable Visio + PDF** with three pages: main architecture, enterprise hardening/review, and flow explanation.

**[Get v1.7.0](versions/v1.7/dist/azure-visio-1.7.0.zip)** | [Detailed setup](versions/v1.7/README.txt)

**715 bundled icons.** Automatic startup and output folders; no extra icon downloads, SVG setup, or runtime package installation.

## Install in Microsoft Scout

Requires **Python 3.10+**, preinstalled **ReportLab/Pillow**, and Scout skill/file/Python permissions. Desktop Visio is not needed to generate files; existing desktop-editing workflows remain separate.

1. Download the skill ZIP above, not GitHub's source archive. Extract it locally, preferably outside OneDrive; keep **all 11 files together**.
2. Paste the installation prompt below into Scout, replacing `[full folder path]`.
3. Approve legitimate access requests, then start a **new chat**.

> Install azure-visio from [full folder path]. Register or update SKILL.md and copy all companions into its resource directory. Preserve unrelated skills/settings. Run portable_visio.py startup with bundled icons; report missing prerequisites without installing packages.

## Use in Cowork

Import the same ZIP through **Customize > Skills > Add > Upload skill**, then start a **new task**. Cowork uses preinstalled ReportLab/Pillow and finishes directly, with **no Scout handoff**. Host approvals still apply.

## Create a diagram

Attach your source or give Scout its full local path. For OneDrive/SharePoint documents, provide the link for approved Microsoft 365 reading.

| Input | Include |
| --- | --- |
| Requirements: Word, PDF, Markdown or text | Goals, services, flows, security and recovery needs. |
| Sketch/screenshot: PNG or JPG | Readable labels, arrows and boundaries. |
| BOM: Excel or CSV | Services, SKUs, quantities, regions and known connections. |
| JSON | A [skill model](versions/v1.7/example-model.json) or resource inventory. |
| ARM template/topology export | Resource definitions, sanitized parameters, connections or a topology screenshot. |

> Use azure-visio to diagram the attached source. Preserve its components and connections, flag uncertainties, and deliver three-page editable Visio and PDF files with official icons and right-angle connectors.

**Example requirement:** "Draw an App Service web app using Azure SQL, Blob Storage, Entra ID and Azure Monitor. Leave unspecified sizing and recovery targets as open decisions."

Source reading depends on host tools and usage rights; only the skill-model JSON is a direct renderer input. BOMs and ARM dependencies do not establish runtime traffic. Templates are never deployed. Remove secrets and clarify ambiguous sources.
